## Where things stand, in five lines

1. Stage D is complete: 1,560 search units on 156 MiniGrid/BabyAI games (logs/dev_reading.log).
2. The registered contrast, search AUROC minus mechanics AUROC on 26 GVGAI games, has a smallest detectable difference of 0.51 (logs/sdd.log). If the true difference equals the development one (0.0818 for N), the registered test finds it with probability 0.0345 to 0.0517; power 0.80 would need 475 to 887 games (logs/stage_e_diagnosis.log, Section 1). No change of threshold or agents fixes that; the number of games is the limit.
3. The 25% capped-share rule would void every search measure on the development data (31.2% capped), yet capping costs the state-count AUROC almost nothing: 0.7115 to 0.7158 for N at every ceiling from 10,000 to 5,000,000 states (logs/stage_e_diagnosis.log, Section 3).
4. The fewest actions to a win ranks completion well even among games with the same mechanics score: AUROC 0.8277 for N, 0.8487 for I1 (Section 7). A test on those pairs has power 0.75 for N at the registered level on 26 games, if the confirmatory AUROC is near the development one (Section 6).
5. Stage E, a repeat of the development search that records when the first win is seen, is running (28 sessions, about 6.7 days, logs/make_stage_e_manifest.log). It is needed to pick the ceiling C with its effect on the development counts known.

**2. Primary search score: the fewest actions to a win within C states (L_C), or the state count (H_C)?**
Counts, same-mechanics pairs, N: L 0.8277 against H_C 0.6321 on development data; power 0.75 against 0.31 (Sections 6 and 7). H_C is the construct v0 named ("number of reachable states"); L is already a v0 secondary measure.

**3. Which pairs does the primary test compare: games with the same mechanics score, or all games?**
Same-mechanics pairs answer "does search predict completion where mechanics cannot tell levels apart". All pairs answer only "does search predict completion". Power for N with L_C: 0.75 against 0.88.
Recommended: **same mechanics score**.
Answer: **Same mechanics score**: the primary test compares between-game pairs whose games have the same mechanics score. (Rahul Kumar Mishra, 14 November 2026)

*EXPLORATORY.* What each form would do.
- *(a) A share of levels.* On the pilot it voids L_C at 10,000 for any X above 40%, and at every C for X = 75%; at X = 50% it voids at 10,000 only (100,000 sits exactly at 50.0%, which is not fewer than 50%). On the development data it voids nothing at any C for any X up to 75%.
- *(b) A number of games.* On the pilot 3 of 4 games (bait, labyrinthdual, watergame) have a level with a win within C at every candidate; scaled to the 25 confirmatory games, that clears G = 5, 8 and 13 at every C. On the development data 87.2% to 95.5% of the 156 games have one. It voids nothing on either set at any of the values shown.
- *(c) A number of pairs the score can order.* It cannot be computed on the pilot: it needs the agents' outcomes, and no pilot agent row exists. On the development data, 95.5% to 99.7% of the eligible same-S_M between-game pairs have at least one unit with a win within C, for every agent and every C, so it would void nothing at any threshold below 95%.

*Recommendation: form (a), with X = 50%: "L_C is void if fewer than 50% of the confirmatory levels show a win within C."* Reasons. (1) It is read from the search rows alone, so whether L_C is void is known when the confirmatory search is done and before any agent unit runs; form (c) waits for the agents and can void the score for one agent and not another, although the score's resolution does not depend on the agent. (2) It measures what the rule is about, the share of levels the score tells apart from "beyond C"; form (b) counts a game with one level of five showing a win as fully resolved. On the pilot the wins come by game (labyrinthdual 5 of 5, watergame 5 of 5 at 1,000,000, rivers 0 of 5), so (a) and (b) agree there, and (a) is the simpler to state and to check. (3) At X = 50%, when L_C is not void, at least as many levels carry a length as sit in the one tie at the bottom, so the score still orders levels by how far the first win lies and does not reduce to "a win seen within C, or not". It mirrors the rule for S_M in Section 7.6 in kind. (4) It separates the cases the pilot and the development data show: void at 10,000 on the pilot (40.0%), where the score has too little resolution; not void at 1,000,000 on the pilot (65.0%) or anywhere on the development data (75.8% to 90.6%).
*What would make it wrong.* (1) Wins on the confirmatory levels packed into the games of one S_M group: half the levels could show a win while most eligible pairs, which come only from inside the four S_M groups, are tied; form (a) would let that through and form (c) would catch it. (2) A share below 50% that still ranks completion well. On the development data most units beyond C were units the agents failed, but not all: at 1,000,000, N and R each completed 35 of the 162 units beyond C (21.6%) and I1 7 (4.3%) (logs/pilot_margins.log, Section 5), so the ties there cost something and a level beyond C is not a sure failure. Whether a score that resolves fewer than half of its levels could still rank completion on GVGAI is not known, and the pilot has no agent outcomes to test it; X = 50% would void such a score. *Corrected 24 November 2026:* this point first said that the levels beyond C "were mostly levels the agents failed, so ties there cost little", which those counts show to be too strong.
